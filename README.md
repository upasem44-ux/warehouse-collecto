# Warehouse Collecto — دواكم

تطبيق تحصيل ميداني يعمل محلياً دون اتصال دائم بالإنترنت.

## تسجيل الدخول وإدارة الحسابات

- عند أول تشغيل، تظهر شاشة إعداد مدير النظام لإنشاء أول حساب. لا توجد كلمة مرور افتراضية أو حساب خلفي ثابت.
- بعد ذلك تظهر شاشة «مرحباً بك في دواكم» لتسجيل الدخول باسم المستخدم وكلمة المرور.
- مدير النظام يستطيع إنشاء حسابات موزعين، وإيقافها أو تفعيلها، وإعادة تعيين كلمات المرور.
- الحد الأدنى لكلمة المرور 10 أحرف. تُخزن بصمة كلمة المرور باستخدام PBKDF2-HMAC-SHA256 مع ملح عشوائي مستقل (210,000 دورة)، ولا تُخزن كلمة المرور كنص صريح.
- بعد خمس محاولات دخول فاشلة يُقفل الحساب مؤقتاً لمدة 10 دقائق.
- تُسجل أحداث الدخول وإنشاء الحسابات وتغيير كلمات المرور في سجل تدقيق محلي.

## حدود النسخة الحالية — مهم

- حسابات المستخدمين محفوظة في قاعدة SQLite على الجهاز نفسه. إنشاء حساب من هاتف المدير **لا** ينشئه تلقائياً على هاتف الموزع الآخر.
- التوزيع الفوري للحسابات بين أجهزة متعددة يحتاج خادماً مركزياً أو خدمة API آمنة، مع اتصال LAN/VPN، ومصادقة وصلاحيات مفروضة من الخادم. لا تعتبر صلاحيات الواجهة وحدها حاجزاً أمنياً كافياً.
- قاعدة البيانات المحلية ليست مشفرة حالياً بتشفير SQLCipher؛ حماية Android sandbox لا تمنع الوصول عند اختراق الجهاز أو عمل root أو استخراج نسخة من بيانات التطبيق.
- حالة «بانتظار المزامنة» لا تعني وجود مزامنة مركزية مكتملة. تكامل LiveExPro 8 لم يُنفذ بعد ويحتاج مخطط قاعدة البيانات ووسيلة الربط المصرح بها من جهاز المحل.
- لا يمكن ضمان عدم الاختراق أو الانهيار بنسبة 100%. قبل الاستخدام المالي الفعلي يلزم اختبار على أجهزة متعددة، وخطة نسخ احتياطي واستعادة مجربة، ومراجعة أمنية مستقلة، وربط مركزي آمن.
